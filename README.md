# ADA Platform

ADA is a responsive sports-and-gaming **demonstration** platform. The current interface uses fictional credits and illustrative content only.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Safety boundary

- No real-money deposits or withdrawals.
- No real-money wagers.
- Balances, teams, odds, events and rewards are fictional.
- No payment provider or crypto wallet connection is integrated.

## Stack

Next.js, React, TypeScript, Tailwind CSS and Lucide icons.
